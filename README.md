# Full-Stack Deployment & Project Architecture

Created by Chinmay C for the Thiranex web development assignments.

## Start
Open `index.html` in a browser (for ES module projects use `python -m http.server 8000`).

## Features
- Modular ES6 frontend architecture
- Client-side hash routing
- Product catalog search/category filtering
- Persistent localStorage cart
- Responsive layout

**Important:** This is a frontend-only demo, not an actual full-stack backend. Deploy as a static website on Netlify or Vercel. No deployment has been performed.
